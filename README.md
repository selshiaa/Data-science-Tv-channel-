# TV Channel Data Analysis & Power BI Dashboard

## Project Overview

This project focuses on analyzing TV channel data to identify useful patterns, trends, and insights using data science and visualization techniques.

The dataset was cleaned and analyzed using Python, and an interactive Power BI dashboard was created to present the findings in a clear and visual format.

## Objectives

- Clean and preprocess the TV channel dataset.
- Handle missing, inconsistent, and invalid data.
- Perform exploratory data analysis (EDA).
- Identify important patterns and trends in the dataset.
- Create meaningful data visualizations.
- Build an interactive Power BI dashboard for analysis.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Power BI
- Microsoft Excel
